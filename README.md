## Research Question
This project examines whether consumers are more willing to pay for AI-designed T-shirts than for T-shirts designed by a professional design team within the company, and whether trust, AI familiarity, and product added value shape this relationship.

## Project Overview
This repository contains the data, documentation, and code for my final project on consumer responses to AI-designed products. The study uses a scenario-based survey experiment to examine how product design source influences willingness to pay.

The project is based on a 2 × 2 between-subjects experimental design:
- Design source: AI design vs. professional design team within the company
- Product added value: high vs. low

The main variables in the dataset include:
- experimental group assignment
- willingness to pay
- trust
- AI familiarity
- basic demographic variables

## Dataset Description
The dataset was collected through an online questionnaire experiment (from Credamo). Respondents were randomly assigned to one of four product scenarios and then asked to answer a series of questions measuring willingness to pay, trust, AI familiarity, and related variables.

The cleaned dataset is stored in: "问卷数据.csv"
